# Pig Game 🎲

A simple dice game built with **Vanilla JavaScript**, **HTML**, and **CSS**.

## 🎮 Rules
- Roll the dice to add to your current score.
- If you roll a 1, you lose your current score and the turn passes to the other player.
- Click **Hold** to save your current score to the total.
- First player to reach 100 points wins.
